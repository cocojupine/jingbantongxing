## 维护方式

- 原仓库没有 React / TypeScript 源码，`code-path` 仅是构建包里的调试标注。
- `assets/ui-repairs.js` 保存本地状态、收藏、导航和会话辅助逻辑；`assets/ui-repairs.css` 保存局部布局调整。
- `python scripts/apply-ui-repairs.py` 从已审核原版生成组件级补丁，检查每段替换以及地图、时间、登录、路由的排除项。
- `scripts/ui-repairs-state.json` 记录上次生成文件的散列。脚本会拒绝覆盖其他人改过的文件；发生合并冲突应先人工核对，不能直接重新生成覆盖。
- 本分支与 `fix/stories-back-home` 都改动同一构建文件中的故事返回逻辑；合并前需协调该处。地图、问卷分支未修改。
- 浏览器只保存当前设备的演示数据；不是实际的账号系统。退出清空当前聊天和待处理通话小结，保留该演示身份的档案、关联、预约与收藏。
