# 鲸伴同行 · 静态 Demo

面向孤独症人士及家长的海洋公园游园演示项目。本仓库统一管理现有页面、静态资源和 UI 稿件，后续代码与界面迭代均在此目录进行。

## 目录

```text
鲸伴同行-demo-发布包/
  index.html       # App 入口
  mockup.html      # 手机样机展示
  assets/          # 已构建的 JavaScript、CSS 和图片
鲸伴同行-UI稿件/
  样机版/
  透明背景版/
```

## 本地运行

安装 Python 3 后，在仓库根目录运行：

```powershell
python -m http.server 5173 --bind 127.0.0.1 --directory "鲸伴同行-demo-发布包"
```

- App：http://127.0.0.1:5173/
- 游园首页：http://127.0.0.1:5173/#/main
- 手机样机：http://127.0.0.1:5173/mockup.html

请通过 HTTP 服务预览。直接双击 HTML 文件可能无法加载 JavaScript 模块。用 `Ctrl+C` 停止服务。

## 当前基线

- 已包含身份选择、登录注册、个人档案、小白助手、语音交互演示、感官友好书包预约、社交故事和场馆信息页面。
- 本期交付范围为静态页面及演示交互。账号、档案、绑定和预约使用浏览器本地存储；助手回复来自内置知识库。
- 园区地图仍为占位入口。问卷与行后反馈、五感测评报告流程尚未实现。
- 语音功能依赖浏览器支持，部分情况使用模拟内容；字体引用 Google Fonts。
- 初始提交仅有构建产物和 UI 图片，没有原始 React/TypeScript 工程，也没有 `package.json`。发布包中的源码路径标注不代表源码文件已包含，因此不能直接运行 `npm run dev`。

## 后续维护

- 将本仓库作为代码与 UI 的统一工作目录，使用 Git 提交记录每次迭代。
- 后续补充原始工程或新增可维护源码时，放入本仓库并同步更新运行说明。
- 保留静态演示范围；需要修改真实服务接入范围时，先明确需求。
- 每次页面修改后检查对应页面跳转、交互反馈及手机尺寸下的布局，并更新相关 UI 稿件。
- 不提交密钥、真实用户资料、本地浏览器数据或依赖缓存。
