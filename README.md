# 鲸伴同行 · 静态 Demo

面向孤独症人士及家长的海洋公园游园演示项目。本仓库统一管理页面、静态资源与 UI 迭代。

## 开发与预览

需要 Node.js 20+ 和 Python 3。

```powershell
npm ci
npm run build
npm run dev
```

- App：http://127.0.0.1:5173/
- 个人中心：http://127.0.0.1:5173/#/profile
- 手机样机：http://127.0.0.1:5173/mockup.html?route=%23/profile&name=个人中心
- 自动化逻辑测试：`npm test`

修改源码后重新运行 `npm run build` 并刷新页面。用 `Ctrl+C` 停止预览服务。

如只需要查看已构建版本，无需安装 Node 依赖，直接运行：

```powershell
python -m http.server 5173 --bind 127.0.0.1 --directory "鲸伴同行-demo-发布包"
```

## 代码目录

| 目录 | 用途 |
|---|---|
| `src/enhancements.jsx` | 个人中心、收藏、帮助、使用说明、场馆指引与演出页 |
| `src/state.js` | 本地档案、账号切换、数据校验、日期与演出时间逻辑 |
| `src/styles.css` | 全局滚动修复、响应式布局和新版个人中心样式 |
| `src/legacy/` | 从初始包提取并格式化的应用函数，保留原有组件与依赖关联 |
| `scripts/build.mjs` | 基于语法树替换应用函数并构建静态产物 |
| `legacy/original-app.js` | 初始构建包的完整基线，校验 SHA-256 后使用 |
| `鲸伴同行-demo-发布包/` | 可直接托管的 HTML、CSS、JS 和图片 |
| `鲸伴同行-UI稿件/` | 初始版本 UI 图片，保留作为设计参考 |
| `docs/qa/` | 本轮测试结论、浏览器检查记录与新版界面截图 |
| `tests/` | 账号隔离、档案校验、日期和返回逻辑的回归测试 |

初始材料没有原始 React/TypeScript 工程。当前新增了可维护的 JSX、样式和应用函数源码，通过构建脚本复用初始包的依赖。不要直接修改 `assets/app.js`、`assets/enhancements.js` 和 `assets/fixes.css`，它们会在构建时重新生成。

`src/legacy/` 中的函数对应：`pD` 登录、`aR` 档案弹窗、`LH` 首页、`Bl` 导航栏、`mH` 聊天、`gH` 通话、`SH` 书包、`bH` 日期、`EH/wH` 故事列表与详情、`OH/jH` 场馆列表与详情、`Hf` 收藏、`HH` 路由、`SD` 个人中心入口。原包中的源码路径标注仅作参考。

## 演示范围

- 本期为静态页面及演示交互，账号、档案、绑定、预约、收藏保存在当前浏览器。不同手机号和身份的数据分别保存；退出后同账号可恢复。
- 小白回复来自内置知识库，未接入大模型。聊天记录仅保存在当前标签页会话中。
- 语音识别取决于浏览器支持与用户授权。不可用时明确提示使用文字输入；录音效果展示可访问 `/#/chat?demo=recording`，不会调用麦克风。
- 园区地图展示已有场馆分区与服务点指引，没有实时定位和真实路线导航。
- 问卷与行后反馈、五感测评 AI 报告仍待后续迭代。
- 书包预约、绑定和场次均用于演示，不能作为真实订单、邀请或现场服务承诺。

## 分支协作

本轮修改在 `fix/navigation-profile-ui` 分支的独立工作副本中进行，完成检查后推送分支，待审核再合并到 `main`。

提交前运行构建和测试，预览受影响页面，检查跳转、滚动及手机布局。不得提交密钥、真实用户资料、本地浏览器数据或依赖缓存。

详细修复与验证记录见 [测试报告](docs/qa/README.md)。
